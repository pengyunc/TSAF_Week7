Recap of Tutorial 6

In Tutorial 6, the ADF test indicated that the \(\log(CPI_{t})\) series contains a unit root.

  • This means we cannot just remove the trend and fit an ARMA model.

    • \(\to\) We need to first difference the \(\log(CPI_{t})\) series to render it stationary.

  • We then ran the ADF test with drift on \(\Delta\log(CPI_{t})\) and the null hypothesis of a unit root was rejected at 5% level.

    • \(\to\) \(\Delta\log(CPI_{t})\) can be modeled as an ARMA process.
    • So we proceeded with selecting the optimal ARMA(\(p,q\)) order for \(\Delta\log(CPI_{t})\) using a grid search of \(p=0,\dots,4\) and \(q=0,\dots,4\).

  • So what is the purpose of ADF test here?

    • To assist with selecting \(d=0\) or \(d=1\) in an ARIMA model.

    • We may wonder: Can we let an information criterion (AIC or AICc) select \(d\) automatically, alongside \(p\) and \(q\)?

  • This tutorial: Maybe we can replace that decision with AIC, just like we pick \(p\) and \(q\)? \(\to\) we will examine this idea with a simulation

This tutorial

In this tutorial we will use simulation to explore the possible usefulness of the AIC for deciding whether to difference a time series or not, in comparison to the conventional ADF tests.

Simulation Setting

  • Use a sample size of \(n=100\).

  • Fit an AR model with fixed order \(p=2\) and with intercept only: \[\mathrm{ARIMA}(2,0,0):\qquad Y_{t}=\beta_{0}+\phi_{1}Y_{t-1}+\phi_{2}Y_{t-2}+U_{t}\]

  • A restricted version of this model is to take a first difference of \(Y_{t}\): \[\mathrm{ARIMA}(1,1,0):\qquad\Delta Y_{t}=\beta_{0}+\psi_{1}\Delta Y_{t-1}+U_{t}\]

  • Selection Criteria: Select ARIMA(1,1,0) if \(\operatorname{AIC}_{\operatorname{ARIMA(1,1,0)}}<\operatorname{AIC}_{\operatorname{ARIMA(2,0,0)}}\).

  • We will compare the ADF and AIC approaches in two ways:

    1. proportion of “correct” choice of differencing
    2. resulting one-step-ahead forecasting performance.

Simulation: Data Generating Process

Data Generating Process

The data generating process for the simulation will be

\[Y_{t}=\phi Y_{t-1}+U_{t},\qquad U_{t}\sim\text{i.i.d. N}(0,1)\] with \(n=100\) and \(\phi_{1}=1,0.95,0.9,0.85,0.8,0.7,0.6,0.5\).

  • For setting up the code, we select \(\phi=0.9\) (without loss of generality), but we can change it later.

  • The true underlying process is actually AR(1), although we will fit AR(2).

  • When \(\phi_{1}\ne 1\), no differencing is needed for \(Y_{t}\) \(\to\) the correct choice is AR(2)

  • When \(\phi_{1}=1\), \(Y_{t}\) is a unit-root process \(\to\) the correct choice is ARIMA(1,1,0)

Part b: Estimate ARIMA(2,0,0) and ARIMA(1,1,0) models for \(Y_{t}\)

  # b. Estimate ARIMA(2,0,0) and ARIMA(1,1,0) models for Y

  # Estimation of AR(2) model
  ARIMA200 <- lm(Y[t]~Y[t-1]+Y[t-2])
  
  # Estimation of ARIMA(1,1,0) model
  DY <- Y[t]-Y[t-1]
  DY1 <- Y[t-1]-Y[t-2]
  ARIMA110 <- lm(DY[t]~DY[t-1])

Notes

  • Recall we set t = (p+1):n, and p = 2 is the AR order.
  • Why do we use lm instead of Arima this time?
    • This is because when \(\phi_{1}=1\), the series is not stationary.
    • Arima command enforces a stationarity check and will return an error in this case.
    • Beneath the surface Arima is attempting to do “maximum likelihood” estimation, which can be tricky in non-stationary settings, while lm is doing least squares which continues to be workable.

Part c: Compute one step ahead forecast errors

  # c. Compute and store 1-step-ahead forecast errors for each model
  #    in columns 1 and 2 of ForecastErrors

  b1 <- ARIMA110$coefficients
  ForecastErrors[r,1] <- Yf - (Y[n]+b1[1]+b1[2]*DY[length(DY)])

  b2 <- ARIMA200$coefficients
  ForecastErrors[r,2] <- Yf - (b2[1]+b2[2]*Y[n]+b2[3]*Y[n-1])

Notes

  • Yf is the actual 1-step-ahead observation (\(Y_{n+1}\))
  • Forecast errors are computed as: \[\hat{U}_{n+1}=Y_{n+1}-\hat{\mathbb{E}}[Y_{n+1}\mid\mathscr{Y}_{n}]\] where the forecasting equations are: \[\begin{aligned}\text{ARIMA(1,1,0):}&& \hat{\mathbb{E}}[Y_{n+1}\mid\mathscr{Y}_{n}]&=Y_{n}+\color{blue}{\widehat{\Delta Y}_{n+1}}\,\color{black}{=Y_{n}\,+}\,\color{blue}{(\hat{\beta}_{0}+\hat{\psi}_{1}\Delta Y_{n})}\\ \text{ARIMA(2,0,0):}&& \hat{\mathbb{E}}[Y_{n+1}\mid\mathscr{Y}_{n}]&=\hat{\beta}_{0}+\hat{\phi}_{1}Y_{n}+\hat{\phi}_{2}Y_{n-1} \end{aligned}\]

Simulation Code

Part d: Perform the ADF test to check for differencing

  # d. ADF test on Y, store decision in column 1 of ur

  # ADF test with drift, lags=1 (include one augmenting term)
  adf_tstat = ur.df(Y, type="drift", lags=1)@teststat[1]
  ur[r,1] <- 1*(punitroot(adf_tstat, N=n, trend="c", statistic="t")>0.05)
  
  # Store forecast error of ADF-chosen model in col 3 of ForecastErrors
  
  # If ADF test selects unit root use ARIMA110 forecast error:
  if (ur[r,1]==1){
    ForecastErrors[r,3] <- ForecastErrors[r,1]  
  } else { 
    # otherwise use ARIMA200 forecast error:
    ForecastErrors[r,3] <- ForecastErrors[r,2]  
  }

Recall the hypotheses of the ADF test are: \[\begin{align} H_{0}:&\;\varphi=0& &\text{($Y_{t}$ has a unit root)}\\ H_{1}:&\;\varphi<0& &\text{($Y_{t}$ does not have a unit root)} \end{align}\] thus if \(p>0.05 \implies H_{0}\) is maintained, ADF suggests ARIMA(1,1,0) \(\to\) record 1

Part e: Use AIC to check for differencing

  # e. AIC choice between ARIMA(2,0,0) and ARIMA(1,1,0)

  # Store decision in column 2 of ur
  ur[r,2] <- 1*(AIC(ARIMA110)<AIC(ARIMA200))

  # Store forecast error of AIC-chosen model in col 4 of ForecastErrors
  if (ur[r,2]==1){

    ForecastErrors[r,4] <- ForecastErrors[r,1]

Recall that when AIC is used, we select ARIMA(1,1,0) if \[\operatorname{AIC}_{\operatorname{ARIMA(1,1,0)}}<\operatorname{AIC}_{\operatorname{ARIMA(2,0,0)}}\] if this is satisfied, store ur[r,2]=1, and store the forecast error of ARIMA(1,1,0) under ForecastErrors[r,4].
